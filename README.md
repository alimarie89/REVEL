# REVEL Project

A full-stack web application with a public-facing website and team admin dashboard.

## Project Structure

```
REVEL/
├── frontend/          # React website (what visitors see)
├── backend/           # Node.js API & admin dashboard (where team manages data)
├── docs/              # Documentation
└── README.md
```

## How It Works

1. **Backend** manages all your data (workshops, facilitators, schedules, etc.) in a database
2. **Admin Dashboard** (built into backend) lets you and your team update data without touching code
3. **Frontend** (React website) automatically displays the latest data from the backend

No more manual HTML editing! Update once in the dashboard, changes appear everywhere.

## Getting Started

See the README files in `frontend/` and `backend/` folders for setup instructions.
